# Android TV Weather Viewer

This repository contains the Android TV weather frontend.

How to run:
- Open android-tv-weather-viewer-193180/weather_app_frontend in Android Studio.
- Build and run on an Android TV emulator or device.

Highlights:
- Ocean Professional theme (blue + amber accents)
- TV remote/D‑pad navigation with focus states
- Card-based layout: current conditions + multi‑day forecast
- Mock weather data out of the box (no API keys required)
